# Menu Launcher

A small personal Minecraft: Java Edition launcher written in Java (Swing).
It is a Polish launcher: the interface is in Polish.

Polski launcher do Minecrafta: Java Edition, z polskim interfejsem.
Prywatny projekt hobbystyczny.

## What it does
- Downloads the official game files and libraries from Mojang's servers.
- Installs the Fabric loader and mods the user chooses.
- Signs the player in with the official Microsoft device-code OAuth flow
  (Microsoft -> Xbox Live -> XSTS -> Minecraft services).
- Has a local offline-account option for singleplayer testing.

## What it does not do
- It does not store Microsoft passwords.
- It does not contain or redistribute any Minecraft game files.
- It is not sold or monetised, and it is not an official Mojang or Microsoft product.

## Status
Personal hobby project. It is not published as a release.
